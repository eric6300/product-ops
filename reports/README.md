# Reports

Formal analysis reports are generated under these directories:

- `spec-reviews/`
- `cross-platform/`
- `impact-analysis/`
- `architecture/`
- `panels/`

Use `{topic-slug}-{YYYY-MM-DD}.md` for new reports. Every formal report should
include an evidence snapshot and a `## 💡 Insights and Learning` section.

Reports may contain private project information. Review them before publishing.
